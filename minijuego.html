🎮 ¿Cómo se juega?

El compilador necesita procesar este programa. Tú eres el compilador. Avanza por las 4 fases respondiendo correctamente. Cada acierto transforma el código a la siguiente representación.

  • 2 preguntas por unidad — 8 retos en total.
  • 3 vidas — cada error resta una.
  • Si pierdes las 3, el compilador truena y empiezas de nuevo.
  • Cada acierto te muestra cómo se transforma el código en esa fase.
